# Mirror Side（镜维度）

一个 Minecraft **1.21.1 / NeoForge** 模组：新增一个**上下重力相反**的自定义维度 —— **镜维度**，
以及围绕这条分界线展开的一整套玩法：**重力方块加工**、**波粒子**、**波粒观测**、镜面传送门、镜外流放区。

> 下载见本仓库根目录：**`mirrorside-0.3.jar`**（模组本体，最新）+ **`mirrorside-0.3-源码.zip`**（配套脚本与完整源码）
>
> 上一版 `mirrorside-0.2.jar` / `mirrorside-0.2-源码.zip` 仍保留在仓库里，便于对照回退。
> 每个版本改了什么见 **[更新日志.md](更新日志.md)**。

| Minecraft | 1.21.1 |
| 载入器 | NeoForge 21.1.197+ |
| Java | 21 |
| 依赖 | **KubeJS**（必需）、**Pondus**（必需，重力方向）、JEI（可选，看配方） |

## 这个模组是什么

镜维度是一个**以 y=0 为镜面**的独立世界：

- 镜像以下（y < 0）**重力朝上**，镜像以上（y > 0）**重力朝下**；
- 掉落物、下落的方块、生物、玩家**都会在交界处反转**；
- 世界本身是空的（虚空 + 玻璃层），进去之后是"在一片玻璃平面上从零开始搭"。

于是它天然成为一套**新的加工方式的舞台**：把方块的"反复坠落"当成加工工序 ——
让一个方块在分界线上下往复，够次数之后它就变成别的东西。

**它不依赖任何前置模组的世界生成**：维度、生物群系、玻璃层全部由本模组自带的配置
（源码包里的 `kubejs/data/mirror/`）生成，不覆盖主世界、下界、末地的任何内容。

## 核心机制

### 1. 镜维度：一个分界线上下重力相反的世界

| 项目 | 值 |
|---|---|
| 维度 ID | `mirror:mirror` |
| 生物群系 | `mirror:mirror`（冷色调天空 / 雾 / 水色，不下雨） |
| 世界高度 | y = −192 ~ 191（384 格） |
| **镜内**（可正常活动） | y = **−64 ~ 63** |
| **分界线** | y = 0（脚本判定用 y = −1，见下） |
| 玻璃层 | 白玻璃在 ±62/63 与 −64/−65（镜外边界）；**黑玻璃在 0/1 与 −1/−2（上下界面）** |
| 坐标比例 | 主世界 1 格 = 镜维度 1/16 格（便于用同一套坐标找回来） |

**重力怎么反转的**：靠 [Pondus](https://modrinth.com/mod/pondus)（提供"每个实体一个重力方向"的底层）
+ 本模组的补丁：

- 修补 Pondus 在服务端换向瞬间算错"换向前速度"、把速度整体清零的缺陷；
- 保住掉落物的**水平动量**，让它保持真实抛物线、且与准心方向一致；
- 补上 Pondus 白名单没覆盖的**非生物实体**（掉落物 / 下落的方块）；
- 交界处**防抖**：站/停在分界线附近时不会来回翻转（迟滞带 + 确认停留）。

> 掉落的方块与掉落物**由模组在服务端接管**，脚本侧不参与物理 ——
> 这样物理只有一处实现，不会出现"两边各算一次"的抖动。

### 2. 重力方块加工

**玩法**：让一个重力方块（沙子、沙砾、混凝土粉末、铁砧、脚手架……）在**分界线上下反复坠落**，
达到指定次数后，它会：

- **在交界处**变成另一种方块（例：沙砾 ×2 → 铁块、可疑的沙子 ×8 → TNT），或
- **落在指定的落点方块上**时变成另一种方块（例：沙子 ×3 + 落在黑色玻璃上 → 石英块），
- 有时产物以**掉落物**形式弹出（树苗、树苗类），有时还会**往容器里塞东西**（陶罐考古战利品）。

**判定用的"次数"是重力方向的切换次数**，与视觉完全一致：它每穿过一次分界线就 +1。

**三个必须知道的前提**（都是原版机制决定的，不是模组限制）：

1. **下落方块必须真的能掉**。脚手架尤其特殊：原版只在它下方 6 格内**没有结实支撑**时才让它掉，
   所以"把脚手架摆在落点方块上方几格"它永远不会掉，且没有任何报错。
2. **落点必须摆在下落实体所在的那一竖列**。下落实体只在竖直方向动，X/Z 一格都不会挪 ——
   差一格就永远碰不到。游戏内用 `/mirror recipes <关键词>` 会直接告出"落点该摆在哪: x=… z=…"。
   **最省事的做法是把落点方块铺满整个水平面的一层。**
3. **落点方块的"结实程度"会影响结果**。例如脚手架落在满格方块上会当场变成稳定方块、结束加工；
   落在支撑形状不满格的方块（灵魂沙 / 泥巴 / 树叶）上才会继续往复。

**在 JEI 里查**：装上 JEI 后，会多出一个 **「重力方块加工」** 分类，
每条配方显示输入、切换次数、落点（标签会展开成真实物品槽）与产物。
产物是动态的（"变成落点那一块"）时，JEI 会把所有可能的结果轮播展示。

### 3. 镜面传送门

在主世界搭一座 **3×3×3** 的结构：

```
底层 3×3     抛光黑石
中层 3×3     中间那格放玻璃（任意玻璃，取 c:glass_blocks 标签），周围 8 格空气
顶层 3×3     平滑石英
```

拿**望远镜**右键中心那格玻璃即可点燃。传送是**本模组自己实现的**（不依赖 PortalJS）：

- **Y 坐标会重新映射**：主世界 −64~319（384 格）线性压进镜维度的 −64~63（128 格），
  来回自洽 —— 主世界地面 y≈70 进镜维度约在 y≈−20，稳稳落在镜内。
- **到达侧自动建门**：从主世界过去时，落点处会自动搭好并点燃一座回程门，不会被困住。
- 回程不靠坐标反算，而是**找最近的门**（找不到就用 `/mirror back`）。

### 4. 镜外：越界会被流放

镜维度在 y = −64 ~ 63 之外是"镜外"。掉出去不会死，但会被切成**冒险 / 旁观**模式
（进入与离开都会提示）—— 这是设定里的流放区，不是 bug。用 `/mirror back` 或 `/mirror tp` 回来。

## 配方全表（核心 46 条，另见 JEI）

> 0.3 起配方总数是 **535 条**：除了下面这些手写的核心配方，木材 / 铜 / 石材三大家族
> 的变体（台阶、楼梯、墙、砖、抛光、氧化铜……）由脚本按规则展开，并在 JEI 里逐条可查 ——
> 完整清单请在游戏内用 **JEI** 的「重力方块加工」分类查看（对着镜面按用途键即可）。

> `×N` = 需要的重力切换次数；**crossing = 于交界处变**，**landing = 落在指定方块上时变**。

### 基础材料

| 输入 | 次数 | 触发 | 产物 / 条件 |
|---|---|---|---|
| 沙砾 `gravel` | ×2 | crossing | 铁块 |
| 沙子 `sand` | ×3 | landing | 石英块（落在**黑色玻璃**上） |
| 红沙 `red_sand` | ×8 | crossing | 金块 |
| 红沙 `red_sand` | ×4 | landing | 荧石（落在**荧石**上） |

### 考古：可疑方块

| 输入 | 次数 | 触发 | 产物 |
|---|---|---|---|
| 可疑的沙砾 | ×8 | crossing | 绿宝石块 |
| 可疑的沙砾 | ×4 | landing | 煤矿块 **+ 往陶罐里塞 1 个古迹废墟战利品**（满罐也触发） |
| 可疑的沙子 | ×8 | crossing | TNT |
| 可疑的沙子 | ×4 | landing | 煤矿块 **+ 往陶罐里塞 1 个沙漠/海底废墟战利品**（满罐也触发） |

### 铁砧（三级递进）

| 输入 | 次数 | 触发 | 产物 |
|---|---|---|---|
| 损坏的铁砧 | ×4 | crossing | 开裂的铁砧 |
| 开裂的铁砧 | ×4 | crossing | 铁砧 |
| 铁砧 | ×8 | landing | **变成落点那一块**（矿物块 / 金属块 / 铁砧工艺的粗矿块） |

### 其它

| 输入 | 次数 | 触发 | 产物 |
|---|---|---|---|
| 脚手架 | ×8 | crossing | 蜘蛛网 |
| 脚手架 | ×4 | landing | 对应树苗（落在任意**树叶**上，掉落物形式） |
| 滴水石锥 | ×16 | crossing | 滴水石块 |

### 混凝土粉末（16 色 × 2 条）

| 输入 | 次数 | 触发 | 产物 |
|---|---|---|---|
| 任意颜色混凝土粉末 | ×8 | crossing | 同色**陶瓦** |
| 任意颜色混凝土粉末 | ×4 | landing | 同色**带釉陶瓦**（落在**熔炉**上） |

> 16 色共 32 条由脚本循环生成 —— 手抄 16 色极易写错一个字母，
> 而写错的表现只是"某两种颜色没反应"，非常难查。

## 工作台配方

把「发光地衣」当作**镜面的碎屑**，与沙子 / 沙砾揉在一起，即可**自己造出可疑方块**
（不必满世界找考古点）：

| 原料（无序） | 产物 |
|---|---|
| 沙子 + 发光地衣 | 可疑的沙子 |
| 沙砾 + 发光地衣 | 可疑的沙砾 |

## 安装

1. 装 **Minecraft 1.21.1 + NeoForge 21.1.197 或更高**。
2. `mods/` 里放入：
   - `mirrorside-0.3.jar`（本模组，最新；旧版用 `mirrorside-0.2.jar`）
   - **KubeJS**（必需）与其自带依赖 Rhino
   - **Pondus**（必需，重力方向）
   - JEI（可选，装了才能在 JEI 里看到"重力方块加工"与"波粒观测"两个分类）
3. 解压 **`mirrorside-0.3-源码.zip`**，把其中的 **`kubejs/`** 整个目录放进游戏目录
   （与 `mods/` 同级）。**维度、生物群系、535 条配方、波粒观测、指令全部在 `kubejs/` 里** ——
   只放 jar 是拿不到玩法的。
   > ⚠️ 若目标整合包已有 `kubejs/`，请**合并**（本包只新增 `data/mirror/`、
   > `data/pondus/`、`server_scripts/mirror_*.js`、`startup_scripts/mirror_*.js`、
   > `client_scripts/`、`config/mirror_dimension.json`）。
4. 启动游戏。第一次进世界后维度即注册完成，用 `/mirror portal` 或按
   [传送门结构](#3-镜面传送门) 自己搭一座门即可进入。

> 本模组**不包含** KubeJS / Pondus / JEI 本体，请自行从各自发布页下载对应 1.21.1 NeoForge 版本。

## 游戏内指令

全部挂在 `/mirror` 下：

| 指令 | 作用 |
|---|---|
| `/mirror tp` / `/mirror back` | 往返镜维度 |
| `/mirror portal` | 在你面前直接搭好并点燃一座门 |
| `/mirror info` | 当前维度、坐标、重力方向、分界线等状态 |
| `/mirror gravity` | 重力总开关与参数（排查"重力没反转"时先看这里） |
| `/mirror recipes [关键词]` | 列出加工配方；**排查"配方不生效"时看它的采样区**：活动范围、最近 3 秒的高度区间、**落点该摆在哪（x/z）**、探针旁边出现过什么方块 |
| `/mirror crafting` | 工作台配方注册情况回读 |
| `/mirror sound` | 传送门音效开关 |

## 已知限制

- **水不会向上流**（原版流体没有"反重力"这套）。镜维度下半区的水依然是往下流。
- 维度类型改动后**必须退出世界再进**才生效（这是 Minecraft 自身的缓存行为，不是本模组的问题）。
- 本模组的世界生成是**虚空 + 玻璃层**，没有地形 —— 这是设定，不是缺失。
- 0.1 → 0.2 期间**删掉了一条配方**（脚手架 + 灵魂沙 → 地狱疣）：它需要为"脚手架一碰方块就重生"
  这件事额外引入专用机制，实测每次都会带来新的不稳定，最终判定性价比不成立而移除。
  详情见源码包内的开发记录。

## 版本记录

### 0.3

> 主题：**波粒子**与**波粒观测**两套新玩法，加上容器保真、材质重做与配方大扩容。
> 逐条明细见 **[更新日志.md](更新日志.md)**。

- **波粒子**（新物品链：波 → 粒 → 波粒子）：右键任意方块给它加上重力特性，它就会坠落在分界线上往复；
  **带方块实体的方块**（刷怪笼、箱子、木桶……）与**挖不动的方块**（基岩一类）同样适用，每格只生效一次。
- **波粒观测**（新多方块玩法）：四个波粒块围住中间那格，放上要观测的方块、拿**望远镜**右键 ——
  等价于把这套引力配方手动跑一遍（方块→方块 / →物品 / →实体），**复用全部 535 条引力配方**，
  另有冰→蓝冰、羊毛(下方放锁链)→蜘蛛网、灵魂沙→下界疣、蛋糕→悦灵四条专用配方，
  以及**染色方块随机换色**（13 个族 × 16 色，同类型不同颜色）。
- **配方 46 → 535 条**：木材/铜/石材家族全面展开（台阶、楼梯、墙、砖、抛光、氧化铜……），
  新增波粒链、干海带→海晶石→海晶灯、骨块→山羊角（8 种乐器随机）、幽匿系列等。
- **容器保真**：推箱子/木桶不再"爆出内容物刷物品"；变成掉落物后捡起重新摆出，**内容物仍在**
  （连同自定义名字与锁）。
- **修掉一次存档崩溃**（掉落物数据缺 `id` 导致物品无法序列化），并且**进世界时会自愈**
  背包里已存在的坏数据。
- **材质重做**：传送门改为 48 帧动态贴图、黑白过渡连续；镜面方块加了连续渐变与对角高光，不再像瓷砖。
- **镜维度永远晴天**（保留天空光）；新增**针尖对麦芒**（spindle）地标结构。
- JEI 同步：535 条加工配方 + 552 条波粒观测配方（新增「波粒观测」分类，工作方块为波粒块）。

### 0.2

- 版号 0.1 → 0.2（模组元数据、产物文件名同步）。
- **删除**配方「脚手架 ×4 + 落在灵魂沙上 → 地狱疣」及其两套专用机制
  （"碰到过就算数"与"按竖列计数"）。脚手架现在只有 2 条配方：×8 → 蜘蛛网、×4 + 树叶 → 树苗。
- 修复：同一竖列的多个下落方块**共用计数器**导致切换次数暴涨、瞬间全部变蜘蛛网的问题
  （现在一律按实体计数）。
- 排查体验：`/mirror recipes` 新增「落点该摆在哪 x/z」与「它这一列实际有什么 / 你要的就在隔壁差几格」，
  专治"落点摆错一列 = 看起来像配方坏了"。
- JEI 数据同步：46 条配方（去掉地狱疣那条）。

### 0.1

- 首个公开版本：镜维度、重力反转、传送门、重力方块加工（47 条）、工作台配方。
